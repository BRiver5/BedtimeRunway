# Bedtime Runway — План реализации

> «Move your sleep, gently, to where it needs to be.»
> Плавный сдвиг режима сна к новой цели (ранняя смена, рейс, экзамен):
> приложение учит твои внутренние часы по записям ночей и строит план отбоя
> на каждую ночь с ограничением на сдвиг за ночь.

---

## 0. Архитектурные решения

- Полностью локальное: `expo-sqlite`, без бэкенда, без уведомлений.
- Заблокировано всё чувствительное, включая `INTERNET` и `POST_NOTIFICATIONS`;
  нужна только вибрация (`VIBRATE`).
- Тема всегда light: полночный индиго `#2E2163`, рассветный янтарь, «лунный» фон.
- Время ночи хранится «от полудня» (0 = 12:00 вечера, 1440 = 12:00 следующего
  дня) — отбой и подъём в одном отрезке без перехода через полночь.
- Все обращения к БД через мьютекс (`src/data/repo.ts`), пересборки стора по
  очереди, конфликты — один раз на версию после отрисовки.
- Не медицинское приложение: везде «estimate», не диагноз.

| Разрешение | Зачем |
|---|---|
| `VIBRATE` | haptics на тапах/сохранении/перетаскивании, выключается в Settings |
| `POST_NOTIFICATIONS` | не используется, заблокировано |

## 1. Движок (`src/lib`) — связка модулей

1. **`phase.ts`** — накапливаемая оценка внутренних часов: два одномерных фильтра
   Калмана. Середина сна дрейфует (шум процесса на день); ночь с будильником
   меряет фазу хуже и смещена раньше — поправка на половину недосыпа.
   Потребность во сне учится только по свободным ночам. Состояние в
   `meta.model`, дообучается только новыми ночами; правка/удаление прошлой
   ночи или смена `MODEL_VERSION` → пересборка из журнала.
2. **`alertness.ts`** — упрощённая двухпроцессная модель Борбели (S — давление
   сна, C — циркадная волна), дневной сон в заданный момент.
3. **`runway.ts`** — план: точное ДП по ночам, состояние — сдвиг часов (шаг
   5 мин, ±7 ч), действие — сдвиг за ночь в пределах темпа. Цена: недосып² (с
   учётом жёстких подъёмов: нынешний будильник до цели, цель после), усилие
   сдвига, провал бодрости на событиях (× важность), время без сна в постели,
   терминальный штраф за недоход до фазы цели. На ночах, обрезанных будильником,
   план ложится до 30 мин раньше часов. Отбой, заданный жестом, не двигает часы
   быстрее темпа — засыпание не раньше чем за 30 мин до «естественного».
   `scoreSequence` — цена любой последовательности (тест сверяет ДП с полным
   перебором).
4. **`changes.ts`** — изменения (темп, время/день начала цели, потребность, дневной
   сон, отбой сегодня) + `whatIf()` честным перепланированием.
5. **`conflicts.ts`** — «не успеем к цели», «событие при низкой бодрости»,
   «короткие ночи из-за будильника»; выходы (одиночные и связки) проверены
   перепланированием, ранжированы по снижению цены, с понятным эффектом.
6. **`explain.ts`** — «почему этот отбой» и разложение бодрости события.
7. **`history.ts`** — траектория фильтра, социальный джетлаг, соблюдение плана,
   качество по длительности сна с интервалами Уилсона.

## 2. Модель данных

| Таблица | Поля |
|---|---|
| logs | night (дата вечера), bed, wake (от полудня), alarm, quality 1–5 |
| anchors | id, name, date, time (от полуночи), importance 1–3, nap |
| planned | night, bed, wake — снимок плана сегодняшней ночи |
| meta | settings (goal, alarm, pace, needOverride, usual times, haptics), model, modelVersion, modelThrough |

## 3. Экраны (6)

1. **Home** (Command Bar Bottom) — hero `PhaseDial` (сутки по кругу: окно сна
   сегодня, окно цели, метка фазы), «почему» + цель, баннер конфликтов, лента
   `RunwayStrip`, события со свайпами (дневной сон / удалить), последние ночи
   (тап — правка, удержание — меню), липкие заголовки; снизу панель Log night /
   Add event / What if.
2. **Runway plan** — `SleepBand` сегодняшней ночи перетаскивается: живое
   сравнение (сон, день выхода на цель, худшее событие, «пролежишь без сна»),
   «Why this bedtime», конфликты с выходами, ночи по одной.
3. **Event detail** (master-detail) — ожидаемая бодрость и её две компоненты,
   `AlertnessCurve` со скрабом пальцем, ночь перед, дневной сон, инлайн-правка.
4. **What if** — темп / время цели / день начала / потребность во сне: две
   колонки Now → If и список изменившихся ночей, Apply.
5. **Stats** — 2/8 недель перестраивают всё; 7 секций: кольцо «% от потребности»
   + часы + потребность, `NightBars` (тап — ночь, отмечается и в тренде),
   `PhaseTrend` (оценка ± разброс, сами ночи, линия цели), будильник vs свободные
   + социальный джетлаг, тепловая карта качества, отбой против плана, хорошие
   ночи по длительности с Уилсоном.
6. **Settings** — цель, будильник до цели, темп, потребность (учиться/вручную),
   обычное время (априор), вибрация, стереть данные.
